# PairTrading
Pair Trading is an investment strategy where 2 stocks will traded together. The program begins with the first ticker(stock) being picked which should be in Yahoo Finance. Similarly when the program is executed the user picks another stock. Then the results are shown: Date (4 years), Open, High, Low, Close.
Next to it will will same Open, High, Low, Close but for the second stock. Then the two averages of the 2 stock prices. Then the ratio, 5 Day Monthly Average (5 DMA), 20 Day Monthly Average (20 DMA), 20 Day Standard Deviation (20 STD), Z-Score, Signal (Whether to by or not), Q for quanitity, Amount for 2 stocks, CUM-Q (Cumulative Quanitity) for two stocks separately, CUM-AMT (cumulative amount), M2M (Mark To Money), Profit, and Profit%.

Then a summary is also executed which displays: Total Profit, Average Profit%, Maximum Profit%, and Minimum Profit%.
